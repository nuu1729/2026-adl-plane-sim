# 揚力ラボ — 飛行機はなぜ飛ぶのか

高校〜大学初年級向けの、揚力の仕組みを視覚的に学べる 3D シミュレーション教材です。
`index.html` 1 ファイルで動作します（ブラウザで開くだけ。ライブラリを CDN から読み込むためインターネット接続が必要）。

## 物理モデル

| 段階 | 手法 |
|---|---|
| 翼型 | NACA 4 桁翼型（余弦間隔・150 パネル） |
| 2 次元翼 | 線形渦パネル法（クッタ条件）→ Cp 分布・Cl・Cm |
| 失速 | Kirchhoff/Beddoes–Leishman のはく離点モデル（約 14° から Cl 低下・Cd 増加） |
| 3 次元翼 | プラントル揚力線理論（非線形・ニュートン法）→ CL・誘導抗力・吹き下ろし角 |
| 飛行力学 | 縦 3 自由度（x, z, ピッチ）、RK4・固定 120 Hz。力は揚力・抗力・重力・推力 |

物理エンジン（`AeroLab`）は Three.js に依存しない独立したスクリプトで、描画・UI はその結果を読むだけです。

## 主な機能

- モード：風洞（機体固定）／(A) 動力飛行（滑走路から離陸）／(B) 滑空
- 翼面を Cp で色分け、GPU 粒子による流線、翼端渦・吹き下ろし、4 つの力の矢印
- 翼断面 2D ビュー：煙パルスで「等時間通過説」が誤りであることを示す
- グラフ：Cp 分布・Cl–α 曲線・極曲線
- ステップ解説：①気流 → ②圧力差 → ③吹き下ろし → ④揚力 → ⑤滑空
- 起動時のセルフテスト（Cl–α の傾き ≈ 2π/rad、クッタ条件、楕円翼 e = 1 など 16 項目）
